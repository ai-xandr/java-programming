# Практическая работа 1

Класс для работы с матрицами комплексных чисел.

### Структура
- `Complex.java` — класс комплексного числа
- `CMatrix.java` — класс комплексной матрицы (операции: +, *, /, det, транспонирование)
- `Main.java` — консольный интерфейс для ввода и проверки

### Запуск
```bash
javac *.java
java Main
